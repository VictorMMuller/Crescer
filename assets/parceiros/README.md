# Identificações visuais dos parceiros de referência

Este diretório contém 14 ícones SVG locais associados aos 8 serviços de vagas e às 6 plataformas de cursos.

- `linkedin.svg` é o símbolo da marca LinkedIn do pacote Font Awesome Free (CC BY 4.0, ícone de marca).
- Os outros 13 arquivos são **ícones editoriais/identificadores ilustrativos** construídos para este portal com base no nome e em cores de referência das instituições. **Não são cópias fiéis de logotipos oficiais e não devem ser tratados como tais**.
- A finalidade é identificar sites de terceiros. O Crescer+PR não tem parceria formal, patrocínio ou vínculo com essas organizações.
- Os recursos são armazenados localmente para serem exibidos mesmo sem internet; os links às plataformas exigem internet.
- Para substituir um ícone por um logotipo oficial licenciado, troque o SVG de nome correspondente e respeite os direitos da marca.

Referências consultadas: páginas oficiais dos próprios serviços, além de imagens de marca usadas apenas para orientar a identidade cromática, sem incorporar arquivos de terceiros ao projeto.
