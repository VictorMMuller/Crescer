# Acervo de vídeos

Esta pasta organiza as referências de vídeo usadas no site. O arquivo `videos.json` contém os IDs, endereços e URLs de miniaturas fornecidas pelo YouTube.

Os vídeos não são enviados ao repositório: permanecem no YouTube, com seus direitos autorais e disponibilidade controlados pelos respectivos autores. As capas dependem de conexão à internet. Em caso de erro, o site exibe `capa-indisponivel.svg` como alternativa visual local.

Antes de divulgar o projeto, confirme manualmente a correspondência entre cada ID e o título do vídeo. Parte dos nomes da seleção original ainda precisa ser validada.
